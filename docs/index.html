Features

Everything you'd rice on Linux.
Running on Windows.

No compositor replacement, no hacks. Just pure Win32 API calls like SetWindowPos and DwmSetWindowAttribute.

  1. 01Layout

    Dwindle + Master Layouts

    Hyprland-identical tiling logic. Every new window splits the focused one, or stacks beside a master.

  2. 02Render

    Animated Borders & Blur

    Gradient borders drawn on a Direct2D overlay, plus Mica / Acrylic system blur on Windows 11.

  3. 03Bar

    Built-in Top Bar

    Workspaces, clock, CPU, RAM, Wi-Fi, volume and battery, themed with the rest of your setup.

  4. 04Desktop

    Wallpaper Picker

    Search wallhaven.cc right from deadbeef and swap wallpapers with animated transitions.

  5. 05Launcher

    App Launcher Win R

    Fuzzy app search, an inline calculator and web search, one keystroke away.

  6. 06Scripting

    Lua Scripting

    Write custom window rules and macros in Lua. Changes hot-reload the moment you save.

One binary

Install in a single command.

Run it once and deadbeef installs itself (Start menu entry, Apps & features listing and your first profile), then hands you the Settings app. No installer wizard, no runtime to fetch.

  • Imports only Windows system DLLs
  • Starts tiling at logon via --wm
  • Clean --uninstall restores every window

Live preview

Watch the layout split itself.

Each new window halves the focused one, alternating direction with the aspect ratio, exactly like Hyprland's dwindle. Prefer a big main window? Switch to master and the rest stack beside it.

  • Settings app previews your real monitor size
  • Gaps, borders, rounding and opacity, before you apply
  • Workspaces mapped to Windows virtual desktops

Get started

Tiling in four steps.

From download to a riced desktop in about a minute.

  1. 01

    Download deadbeef.exe

    One ~3.5 MB binary, nothing else to install.

  2. 02

    Run it

    Settings opens on first launch. Nothing tiles until you say so.

  3. 03

    Pick a layout & apply

    Choose dwindle or master, tune the look in the live preview, hit Apply.

  4. 04

    Done

    Press Win+F1 any time for the keybind cheat sheet.
